## Selected Research Projects

### SWaRL — Reinforcement Learning for Code Watermarking
A reinforcement-learning framework for watermarking code-generating LLMs while balancing watermark detectability, execution correctness, and distribution shift from the base model.

### Multi-bit Watermarking for Code LLMs
Training-based watermarking for code generation with differentiable detection and message recovery, targeting reliable multi-bit extraction while preserving functional correctness.

### Agentic RTL Generation & Debugging
LLM agents that combine reasoning with static analysis, simulators, and EDA-tool feedback for spec-to-RTL generation, debugging, and verification.

### KV-Cache Compression for Efficient LLM Inference
Research on reducing LLM inference cost through KV-cache compression and token-reduction strategies while preserving generation quality.

### AFTAB RISC-V Processor
Designed and implemented a RISC-V processor in Verilog as part of collaborative academic research.
