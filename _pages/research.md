My research focuses on **trustworthy and efficient generative AI**, especially for code, hardware, and systems. I am interested in methods that improve capability while preserving correctness, security, efficiency, and verifiability.

## Trustworthy Code LLMs

### Code Watermarking
I develop watermarking methods for code-generating LLMs, including reinforcement-learning-based and multi-bit approaches. A central goal is to improve watermark detectability without sacrificing functional correctness.

### Model Ownership & Attestation
My broader work explores practical mechanisms for ownership verification, attestation, and secure deployment of large language models.

## Agentic AI for Hardware Design

I work on LLM-based systems for **RTL generation, debugging, and verification**. These systems integrate language models with static analysis, simulators, and EDA tools so that the model can reason over tool feedback rather than operate as a standalone text generator.

Current directions include:

- spec-to-RTL generation
- automated RTL debugging
- tool-feedback-driven agents
- verification-aware evaluation
- failure analysis for agentic hardware systems

## Efficient LLM Systems

I study methods that reduce inference cost while preserving model utility, including **KV-cache compression** and token-reduction strategies for long-context generation.

## Model Adaptation & Post-Training

My work uses modern post-training techniques including:

- supervised fine-tuning (SFT)
- reinforcement learning and GRPO
- parameter-efficient fine-tuning (PEFT)
- synthetic data generation
- structured-output optimization
- evaluation pipeline design

## Earlier Research

My previous work includes malicious-behavior detection in ARM SoCs, adaptive graph partitioning for distributed GNN training, custom ASIC architectures for neural-network acceleration, and RISC-V processor design.
